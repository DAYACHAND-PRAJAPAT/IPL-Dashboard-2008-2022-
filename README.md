# 🏏 IPL Team and Player Performance Dashboard

## 🎯 Objective
Analyze IPL data (2008-2022) to understand team strategies, player statistics, and match dynamics using an interactive Tableau dashboard.

## 📌 Goals
- Compare team performances over seasons.
- Identify top batsmen and bowlers.
- Toss and venue impact analysis.
- Visualize scoring patterns, strike rates, and boundaries.
- Interactive filters for deep dive.

## 📊 Dashboard Features
- Team win/loss overview
- Top 10 batsmen & bowlers
- Toss decision analysis
- Run rate heatmaps & 4s/6s trends
- Filters: Season, Team, Player, Venue

## 📁 Data Sources
- [Dataset 1 by Nikhil Sharma](https://www.kaggle.com/datasets/nikhilsharma1212/ipl-complete-player-performance-2008-2022)
- [Dataset 2 by Biswajit Brahmma](https://www.kaggle.com/datasets/biswajitbrahmma/ipl-complete-dataset-2008-2022)

## 📥 How to Use
1. Download `matches.csv` and `deliveries.csv` from Kaggle and place in `/data`.
2. Open `IPL_Dashboard.twbx` in Tableau Desktop or Tableau Public.
3. Explore insights via filters and interactive visuals.

## 🧮 Calculated Fields
- **Strike Rate** = `(Runs / Balls) * 100`
- **Economy Rate** = `Runs Conceded / Overs`

## 📌 Optional Features
- Metric switching (Runs, SR, Wickets)
- Player tooltips with mini profiles
- Forecasting win trends
